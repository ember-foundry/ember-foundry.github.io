# Critter

### Installation

```shells
npm install /Users/craigiswayne/code/ember-foundry/dist/critter/ember-foundry-critter-0.0.*.tgz
```

Then include the styles in your stylesheet:

```scss
@use '@ember-foundry/component-library/src/styles/reset';
@use '@ember-foundry/critter/src/styles/global';
@source '../node_modules/@ember-foundry/critter';
```

```shell
touch .postcssrc.json
```
